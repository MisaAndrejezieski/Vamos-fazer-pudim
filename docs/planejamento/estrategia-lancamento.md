# Estratégia de Lançamento

## Pré-lançamento
1. Finalizar o manuscrito
2. Criar capa no Canva
3. Configurar conta no Amazon KDP
4. Escrever sinopse e descrição do livro

## Lançamento (Dia 1)
1. Publicar na Amazon
2. Ativar KDP Select
3. Ligar anúncios pagos com força total
4. Meta: 100 vendas no primeiro dia

## Pós-lançamento
1. Manter anúncios rodando diariamente
2. Postar 2 vídeos por dia no TikTok/Reels
3. Responder comentários e interagir
4. Ajustar anúncios conforme resultado
