# Vamos Fazer Pudim.

Um manual direto sobre como atingir objetivos usando a lógica fria de causa e efeito.

## Sobre o Livro

Este livro não é sobre autoajuda. Não é sobre motivação. Não é sobre acordar às 5h da manhã e tomar banho gelado.

É sobre processos. É sobre ritmo. É sobre a conta de somar que você precisa fazer todos os dias.

## Tese Central

A vida não é um drama. É uma linha de produção.

Se você colocar os ingredientes certos no ritmo certo, o resultado acontece.

Sem desculpas. Sem drama. Sem mistério.
